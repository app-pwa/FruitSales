# ระบบบันทึกการขายผลไม้ - ความสามารถโดยละเอียด

แอปพลิเคชันนี้เป็นระบบบันทึกการขายผลไม้แบบออฟไลน์ที่ทำงานบนเว็บเบราว์เซอร์ โดยใช้เทคโนโลยี IndexedDB สำหรับจัดเก็บข้อมูล และสามารถติดตั้งเป็น PWA (Progressive Web App) ได้

## 1. ระบบบันทึกการขาย
- **บันทึกการขายผลไม้**:
  - เลือกวันที่ขาย (เริ่มต้นเป็นวันปัจจุบัน)
  - เลือกชนิดผลไม้จากรายการที่กำหนด
  - เพิ่มรายการขายได้หลายรายการต่อการขายหนึ่งครั้ง
  - ในแต่ละรายการสามารถระบุ:
    - เกรดหรือประเภทสินค้า
    - สวนที่ผลิต
    - น้ำหนัก (กิโลกรัม)
    - ราคาต่อกิโลกรัม
- **ระบบคำนวณอัตโนมัติ**:
  - คำนวณมูลค่ารวมของแต่ละรายการ (น้ำหนัก x ราคาต่อกิโลกรัม)
  - คำนวณยอดรวมทั้งหมดของการขาย
- **โหมดแก้ไข**:
  - สามารถแก้ไขการขายที่บันทึกไว้แล้วได้
  - ปุ่มบันทึกจะเปลี่ยนเป็น "บันทึกการแก้ไข" เมื่ออยู่ในโหมดแก้ไข

## 2. การจัดการประวัติการขาย
- **แสดงประวัติการขาย**:
  - เรียงลำดับจากวันที่ล่าสุด
  - แสดงข้อมูลวันที่, ชนิดผลไม้, รายละเอียดการขาย, และยอดรวม
- **การจัดการ**:
  - แก้ไขการขาย
  - ลบการขาย
  - ลบข้อมูลการขายทั้งหมด

## 3. การจัดการข้อมูลพื้นฐาน
- **จัดการชนิดผลไม้**:
  - เพิ่มชนิดผลไม้ใหม่
  - ลบชนิดผลไม้
- **จัดการเกรด/ประเภทสินค้า**:
  - เพิ่มประเภทใหม่ (เช่น เกรด A, เกรด B)
  - ลบประเภท
- **จัดการสวน**:
  - เพิ่มสวนใหม่
  - ลบสวน

## 4. การนำเข้าและส่งออกข้อมูล
- **ส่งออกข้อมูล**:
  - บันทึกข้อมูลทั้งหมดเป็นไฟล์ JSON
  - รวมข้อมูลการขายและข้อมูลพื้นฐานทั้งหมด
- **นำเข้าข้อมูล**:
  - นำเข้าข้อมูลจากไฟล์ JSON
  - มีระบบตรวจสอบไฟล์ก่อนนำเข้าจริง
  - สามารถนำเข้าข้อมูลได้แม้จะเปลี่ยนอุปกรณ์

## 5. การวิเคราะห์ข้อมูล (แดชบอร์ด)
- **กราฟแสดงข้อมูล**:
  - **จำนวนผลผลิตต่อเดือน**: แสดงน้ำหนักผลผลิตแยกตามสวน
  - **แนวโน้มราคา**: แสดงราคาเฉลี่ยต่อกิโลกรัมตามช่วงเวลา
  - **รายได้รายปี**: แสดงรายได้รวมแต่ละปี
  - **ราคาเฉลี่ยต่อกก.**: เปรียบเทียบราคาเฉลี่ยระหว่างปีต่างๆ
- **ระบบกรองข้อมูล**:
  - กรองตามปี
  - กรองตามชนิดผลไม้
  - กรองตามสวน
  - กรองตามประเภทสินค้า
- **แสดงสถิติ**:
  - น้ำหนักรวม
  - รายได้รวม
  - ราคาเฉลี่ยต่อกิโลกรัม

## 6. ระบบลบข้อมูล
- **ลบข้อมูลทั้งหมด**:
  - ลบประวัติการขายทั้งหมด
  - ลบข้อมูลพื้นฐานทั้งหมด (ผลไม้, ประเภท, สวน)
  - มีระบบยืนยันการลบเพื่อป้องกันการลบโดยไม่ได้ตั้งใจ

## 7. คุณสมบัติพิเศษ
- **ทำงานแบบออฟไลน์**:
  - ใช้ IndexedDB สำหรับจัดเก็บข้อมูล
  - สามารถใช้งานได้แม้ไม่มีอินเทอร์เน็ต
- **PWA Support**:
  - สามารถติดตั้งบนอุปกรณ์ได้
  - มี Service Worker สำหรับการทำงานออฟไลน์
  - มี Manifest สำหรับการแสดงผลเหมือนแอปพลิเคชัน
- **Responsive Design**:
  - ออกแบบให้ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์
- **UI สวยงาม**:
  - ใช้ Tailwind CSS สำหรับการออกแบบ
  - มีไอคอนจาก Font Awesome

แอปพลิเคชันนี้เหมาะสำหรับเกษตรกรหรือผู้ค้าผลไม้ที่ต้องการระบบบันทึกการขายที่เรียบง่ายแต่มีประสิทธิภาพ สามารถวิเคราะห์แนวโน้มการขาย และทำงานได้แม้ไม่มีสัญญาณอินเทอร์เน็ต
